Image sources for the lecture on universal approximation and optimization
==========================================================================

Every figure in this folder is an original plot generated by `../make_figures.py` in the
course palette (`notebooks/plotting.py`). No external images are used. The diagrams of the
slides (the two timelines and the digit classifier) are TikZ pictures written inline in the
`.tex` file. The script prints every number that the slides quote.

The target throughout is `g(x) = sin(3x) + 0.3x` on `[-1, 1]`, sampled at 160 equispaced
points unless stated otherwise.

The experiments of notebook 10, same code and seeds
---------------------------------------------------

- `linear_fit.pdf`: the target and its least-squares line.
- `families.pdf`: five building blocks of each of the four families (monomials, Gaussian
  translates of width 0.4 centred on `[-1.5, 1.5]`, hat functions on an equispaced mesh,
  sigmoid neurons of slope 8 plus a constant) and their least-squares fits with
  `m = 2, 4, 8` pieces.
- `sigmoid_construction.pdf`: `sigma(kx)` for `k = 2, 8, 40`; the bump
  `sigma(k(x + 0.3)) - sigma(k(x - 0.3))` for `k = 8, 40`; and the staircase
  `g(s_0) + sum_j (g(s_j) - g(s_{j-1})) sigma(k (x - t_j))` on `m` equal cells with nodes
  `s_j`, midpoints `t_j` and slope `k = 6 / h`, for `m = 8, 32`. Its sup error on a grid of
  2001 points is 0.085, 0.017, 0.004 and 0.001 for `m = 8, 32, 128, 512`.
- `gd_step_sizes.pdf`: gradient descent on `F(w) = (w_1^2 + 20 w_2^2) / 2` from
  `(1.2, 0.6)` with `eta = 0.005, 0.05, 0.095, 0.105` (30 steps; 8 for the last one).
- `descent_lemma.pdf`: `F(w) = w^2 / 2 + sin(2w) / 2`, for which `F'' = 1 - 2 sin(2w)` lies
  in `[-1, 3]`, so `L = 3`. The quadratic models at `w_k = 1.9` for `eta = 1/L` (an upper
  bound; `F` decreases from 1.499 to 1.211) and for `eta = 3.5 = 10.5/L` (not an upper
  bound; the model predicts -0.653 and `F` increases to 2.330).
- `momentum.pdf`: gradient descent and the heavy-ball method (`beta = 0.6`) on the same
  quadratic with `eta = 0.05`, 60 steps.
- `optimizers.pdf`: gradient descent, heavy ball and Nesterov momentum (`momentum = 0.9`)
  and Adam, 300 full-gradient steps on a quadratic with 50 curvatures from 1 to 100
  (learning rate 0.01; Adam 0.05), the Rosenbrock function from `(-1.2, 1)` (0.002; Adam
  0.5) and a `1 -> 16 -> 1` tanh network fitting the target (0.05; Adam 0.03).
- `double_well.pdf`: `F(w) = (w^2 - 1)^2 + 0.3w` from `w_0 = 1.5`. Gradient descent with
  `eta = 0.005`, and the Euler--Maruyama scheme with `sigma = 0.7`, `eta = 0.05`, NumPy
  seed 0, 400 steps each. The right panel is the histogram of a run of 400,000 steps with
  `eta = 0.01` (seed 1) against the normalized Gibbs density `exp(-2F / sigma^2)`.
- `minibatch.pdf`: the `1 -> 16 -> 1` tanh network (PyTorch seed 0) trained for 200 epochs
  with SGD, `eta = 0.05`, on the full batch and on batches of 16 (shuffling seed 1).
- `mnist_training.pdf`, `mnist_predictions.pdf`: the `784 -> 16 -> 16 -> 10` ReLU network
  (13,002 parameters, PyTorch seed 0) trained on MNIST for 5 epochs with Adam, learning
  rate `1e-3`, batches of 64 (shuffling seed 1). The predictions are for six test images
  drawn with seed 4. The MNIST files (LeCun, Bottou, Bengio and Haffner, 1998) are
  downloaded once to `notebooks/data/` from
  `https://storage.googleapis.com/cvdf-datasets/mnist/` and are not part of the repository.
